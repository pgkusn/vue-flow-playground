將目前的左側面板與畫布區域根據 pencil 畫布中的內容與說明，搭配 public/data.json 將資料轉換成 vue flow 所需的格式與樣式呈現在畫面上，完成後應使用瀏覽器進行測試。

data.json 可參考 API 文件：docs/api.md

注意事項：

1. 修改左側面板與畫布區域即可，頂部導覽列的內容維持不變，僅需將背景改成白色
2. 所有的連線皆有動畫效果（animated: true）
3. 起點節點會固定顯示在畫布中，不需顯示在側邊欄
4. 側邊欄不包含最左邊的「旅程設定」與「節點設定」頁籤功能
5. 將節點資料編輯彈窗的內容留空並將背景改成白色，此階段暫不實作
